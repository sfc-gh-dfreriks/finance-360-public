# SAP BDC Finance 360 — Public (anonymous) build

A static, no-login public build of the SAP BDC Finance 360 dashboard, deployed to
GitHub Pages. Dashboards render from a **point-in-time data snapshot** (no Snowflake
connection, no credentials in the browser). The app opens on
Executive Dashboard; Ask Cortex is the first sidebar page.

## How it works

- **Ask Cortex:** the Ask Cortex page and the "Ask Cortex about <page>" buttons show
  answers to each page's default question that were generated by Snowflake Cortex
  (`AI_COMPLETE`) at export time and baked into `public/data/ask_cortex.json`. Your
  own questions need the live app (or an `AGENT_URL` worker exposing `/ask-cortex`).

- **Dashboards:** built with `VITE_STATIC=1`. The client reads pre-baked JSON in
  `public/data/*.json` (one keyed map per endpoint, covering every company-code ×
  fiscal-year filter combination) instead of a live `/api`.
- **Data refresh:** re-run the exporter against the live dashboard server, commit the
  updated `public/data/*.json`, and push — Actions redeploys.
  ```bash
  # from the finance_dashboard_react monorepo, with the server running:
  EXPORT_BASE=http://localhost:3002 node scripts/export-static.mjs
  ```
- **`AGENT_URL` (legacy):** the build still injects this repo variable as
  `VITE_AGENT_URL`, but the in-app agent/Analyst page has been removed, so nothing in
  the UI calls it. The dashboards and baked Ask Cortex answers need no agent.

## Local build

```bash
npm ci
VITE_STATIC=1 npx vite build      # outputs dist/
npx vite preview                  # or: python3 -m http.server -d dist
```

## Deploy

Push to `main` → `.github/workflows/deploy.yml` builds with
`BASE_PATH=/finance-360-public/` and publishes `dist/` to GitHub Pages.

No secrets are stored in this repo. It contains only synthetic SAP demo data.
